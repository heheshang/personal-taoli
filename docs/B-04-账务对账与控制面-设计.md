# B-04 账务、对账与控制面：设计文档

文档状态：`verified`。实现保持 PAPER/控制意图安全边界。

## 1. 模块边界

- `crates/core/src/accounting.rs`：复式账务事件、借贷明细、业务键幂等、余额聚合和不可变历史。
- `crates/core/src/reconciliation.rs`：余额快照、对账运行、差异分类和结果持久化。
- `crates/core/src/control.rs`：控制动作、授权主体、过期语义、幂等请求、完成结果和审计。
- `crates/core/migrations/0004_accounting_reconciliation_control.sql`: B-04 表、约束、索引和不可变触发器。
- `src-tauri/src/commands/accounting_control.rs`: 读取 `TAOLI_DATABASE_URL`,选择单一 smoke 用例并映射统一 `ApiResponse`;不承载领域规则。

## 2. 事务和不变量

复式账务事件先验证每个资产的借贷总额，再在一个事务内写入事件和明细。`business_key` 唯一约束保证重放返回原事件，冲突键不能映射到另一事件；事件、明细和余额快照由数据库触发器拒绝修改。

余额快照要求 `total >= 0`、`free >= 0`、`locked >= 0` 且 `free + locked <= total`。对账合并两侧资产集合：只存在一侧为 `MISSING`，数量接近但不同为 `DELAYED`，其余为 `CONFLICT`；运行与差异在同一事务提交。

控制命令持久化 `actor`、动作、scope、唯一 `request_id` 和 `expires_at_ms`。过期请求直接进入 `EXPIRED`；完成操作只接受 `SUCCEEDED`、`FAILED` 或 `PARTIAL`，且在事务中锁定命令行。每个命令和完成结果都保留审计记录。

## 3. 失败关闭

数据库连接、migration、约束、触发器、唯一键和领域校验失败均返回错误；不以内存状态代替已提交事实。B-04 不拥有订单适配器，也不在任何路径发出外部订单调用。所有 smoke 报告明确 `external_order_calls=0`。

## 4. 接入契约

桌面端调用：

```text
run_accounting_control_smoke({ kind: "ACCOUNTING" | "RECONCILIATION" | "CONTROL" })
```

返回:

```text
ApiResponse<AccountingControlSmokeResult>
AccountingControlSmokeResult = Accounting | Reconciliation | Control
```

缺少数据库环境变量返回 `ACCOUNTING_CONTROL_ERROR`;不支持的 kind 返回 `INVALID_REQUEST`.前端只展示返回的报告,不直接访问数据库或核心模块。

## 5. 发布限制

B-04 验证完成不代表真实账务同步、私有 API 可用或交易许可。真实订单适配器、流水补拉、费用结算和资金释放必须经过独立需求、权限审批、故障演练与 A-05 连续观察评审。
