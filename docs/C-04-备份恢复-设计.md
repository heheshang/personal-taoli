# C-04 备份恢复：设计文档

文档状态：`in_progress`。实现备份恢复模块。

## 1. 模块边界

- `crates/core/src/backup.rs`：备份恢复核心模块，包含备份类型、状态、元数据和备份管理器。

## 2. 备份类型

| 类型 | 描述 | 使用场景 |
|---|---|---|
| Full | 完整备份 | 定期备份、初始备份 |
| Incremental | 增量备份 | 频繁备份、减少存储空间 |
| WalArchive | WAL归档 | 实时备份、PITR |

## 3. 备份状态

```text
InProgress -> Completed
     |
     v
   Failed
Completed -> Restoring
```

## 4. 备份管理器设计

```text
BackupManager {
    backup_dir: PathBuf,
    backups: Vec<BackupMetadata>,
}

impl BackupManager {
    pub fn new(backup_dir: PathBuf) -> Self;
    pub async fn create_full_backup(&mut self, database_url: &str, now_ms: u64) -> Result<BackupMetadata>;
    pub async fn create_incremental_backup(&mut self, database_url: &str, now_ms: u64) -> Result<BackupMetadata>;
    pub async fn restore_from_backup(&self, backup_id: &str, target_database_url: &str, now_ms: u64) -> Result<RestoreResult>;
    pub fn get_backups(&self) -> &[BackupMetadata];
    pub fn get_latest_backup(&self) -> Option<&BackupMetadata>;
    pub fn verify_backup_integrity(&self, backup_id: &str) -> Result<bool>;
}
```

## 7. 失败关闭

- 备份创建必须包含完整的元数据。
- 备份恢复必须验证备份完整性。
- 恢复结果必须包含RPO/RTO测量。
- 所有测试必须在隔离环境运行，不影响生产环境。

## 8. 接入命令

备份管理器可通过以下方式调用：

```text
// 创建备份
let mut manager = BackupManager::new(PathBuf::from("/tmp/backups"));
let backup = manager.create_full_backup("postgresql://test", 1000).await?;

// 恢复备份
let result = manager.restore_from_backup(&backup.backup_id, "postgresql://target", 2000).await?;

// 验证备份完整性
let valid = manager.verify_backup_integrity(&backup.backup_id)?;
```

## 9. 发布限制

备份恢复模块只用于隔离环境验证，不影响生产环境配置和运行。真实备份恢复需要独立的需求和审批流程。
