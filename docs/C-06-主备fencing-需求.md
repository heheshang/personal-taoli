# C-06 主备fencing：需求文档

文档状态：`in_progress`。本阶段实现主备切换和故障隔离能力。

## 1. 目标

建立可重复的主备切换和故障隔离能力，在隔离环境验证系统的高可用性。

## 2. 需求

| 编号 | 要求 | 验收结果 |
|---|---|---|
| C06-R01 | 支持节点注册和管理 | 节点管理功能完整 |
| C06-R02 | 支持fencing令牌生成和验证 | 令牌管理功能完整 |
| C06-R03 | 支持主备切换 | 主备切换功能完整 |
| C06-R04 | 支持心跳检测和故障检测 | 故障检测功能完整 |
| C06-R05 | 支持故障恢复 | 故障恢复功能完整 |
| C06-R06 | 测试结果可追溯 | 生成结构化测试报告 |

## 3. 明确不做

- 不接入真实数据库进行测试。
- 不修改生产环境配置。
- 不执行真实主备切换（仅模拟）。
- 不影响系统正常运行。

## 4. 验证边界

```text
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
npm run build
cargo build --workspace --release
```

主备fencing测试套件必须覆盖所有预定义测试场景，每个测试必须有明确的预期行为和结果验证。
