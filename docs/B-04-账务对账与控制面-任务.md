## 2. 必须通过的行为

1. 每个资产的借贷明细必须平衡；不平衡事件失败关闭，不写入部分事实。
2. 相同 `business_key` 的重放必须返回原事件；内容漂移必须拒绝。
3. 已提交账务事件、明细和余额快照不可更新或删除。
4. 外部余额快照必须满足非负约束和 `free + locked <= total`。
5. 对账结果必须区分 `MATCHED`、`MISSING`、`DELAYED` 和 `CONFLICT`，并持久化运行与差异事实。
6. 账务、对账和控制数据库失败不得以内存结果替代已提交事实。
7. 控制请求必须绑定 `actor`、动作、scope、唯一 `request_id` 和 `expires_at_ms`。
8. 控制请求重放必须幂等；完成结果和审计记录必须可追溯。
9. 过期控制请求只能进入 `EXPIRED`，不得执行任何外部动作。
10. B-04 smoke 的 `external_order_calls` 必须固定为 `0`。
