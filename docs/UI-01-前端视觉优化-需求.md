# UI-01 前端视觉优化：需求文档

文档状态：`verified`（实现与验证完成，等待发布签收；R11 于 2026-09-09 补充并入）。

## 0. 迭代编号与性质

- 编号：UI-01
- 性质：所有者批准（AIDLC 阶段队列之外的特批迭代，手册 §11「等待所有者批准」路径），纯前端展示优化
- 关联：C-01 桌面迁移交付的 Vue 控制台；后端协议为既定边界，本轮不触碰

## 1. 目标

把现有 Vue 观测台从「工程师默认可读」提升为「精致、有层级、信息密度合理」的成品观感。
保留并细化现有浅色绿灰金融基调与安全/只读语义，不推倒重来。

## 2. 现状问题（分析证据）

| # | 问题 | 证据 |
|---|---|---|
| P1 | 字号过小 | 全局 8–12px 文字密布：eyebrow 9px、日志 10px、axis 8px、footer 8px、侧栏标签 8px；指标数值 22px 而标签 8px，反差过大 |
| P2 | 字体失当 | `:root` 全站 SF Mono 等宽，正文可读性差、终端气息过重 |
| P3 | 层级薄弱 | 所有卡片同一 1px 细边框同色背景；卡片标题 h2 仅 11px；无主视觉焦点 |
| P4 | 颜色无语义 | 绿/粉/橙/青/蓝/紫 6 色装饰点平铺于各标题，信息无法一眼分级 |
| P5 | 控件过小且主题冲突 | 按钮 min-height 28px、字号 9px；输入框/表格/开关/Tag 沿用 Element Plus 默认蓝主题，与绿灰基调冲突 |
| P6 | 装饰图形粗糙 | 雷达圈/立方体/山脊线/节点关系图为纯装饰 CSS/SVG，占版面但精密度低 |
| P7 | 窗口默认过小 | 默认 1180×780，minWidth 900 易触发响应式单栏，打开即拥挤 |
| P8 | 侧边栏简陋 | 72px 窄栏、图标为文本符号（◉◎⚙▤⛭）、字号 7–9px |

## 3. 需求表

| 编号 | 要求 | 用户可观察结果 | 验收方法 |
|---|---|---|---|
| UI-01-R01 | 中文字体系统 | 正文/标签为无衬线可读字体栈；数字、代码、JSON 保持等宽；最低可读文字 ≥10px | 浏览器目检 + 样式审查 |
| UI-01-R02 | 字号层级 | 页面标题 ≥15px、卡片标题 ≥13px、指标数值 ≥24px、正文 ≥12px、辅助信息 ≥10px；同级统一 | 浏览器目检五个页面 |
| UI-01-R03 | 颜色系统 | 中性灰阶 + 主绿 + 荧光绿品牌点缀；状态色收敛为成功/警告/危险/信息四个语义；Element Plus 全部组件主色对齐主绿 | 浏览器目检 + 组件操作 |
| UI-01-R04 | 布局与卡片层级 | 卡片标题区/内容区/页边距/间距形成统一尺度系统；卡片 hover 有轻反馈；主次信息视觉可辨 | 浏览器目检 |
| UI-01-R05 | 侧边栏与顶栏 | 图标与间距现代化、当前页状态清晰、品牌完整 | 浏览器目检 |
| UI-01-R06 | 控件尺寸与状态 | 按钮 ≥30px 高、≥11px 字；禁用/loading/运行中胶囊状态清晰 | 控制台页逐一操作 |
| UI-01-R07 | 响应式不破版 | 指标卡、日志、表格、机会卡片、设置表单在 1360×860 与 1100×780 两档齐全可用 | 浏览器缩放到档位目检 |
| UI-01-R08 | 窗口默认尺寸 | Tauri 窗口默认 1360×860（min 1024×680） | tauri.conf.json + 构建产物 |
| UI-01-R09 | 构建门禁 | `npm run build`（vue-tsc --noEmit && vite build）零错误 | 命令输出 |
| UI-01-R10 | 功能回归 | 导航切换、全部按钮、连续观测轮询、设置页加载/保存、报告渲染照常 | 浏览器逐路径操作 |
| UI-01-R11 | 名词项悬浮解释 | 控制台（机会卡指标/账户表头/验证报告字段/回放与重连指标）、设置页全部配置字段、概览/市场面板的名词项，hover 显示中文解释（`el-tooltip` 视觉悬浮，不用 `title` 属性）；未收录词条渲染纯文本、无悬浮、不破坏布局 | 浏览器目检五页面 + hover 弹出词条内容与词条表核对 + 各页面无横向溢出 + R09 构建门禁 |

## 4. 明确不做

- 不改后端：`src-tauri/` 与 `crates/core` 代码、IPC 命令名/参数/返回形状、配置字段（C-01 既定协议边界）。
- 不新增依赖：不引入图表库、图标库、字体包；装饰图形保持纯 CSS/SVG。
- 不新增数据展示：装饰图形只做视觉精度提升，不接入新数据源（雷达/立方体/山脊/节点图保持现有语义与数据）。
- 不做深色模式（范围收敛；如所有者要求，单开迭代）。
- 不改组件逻辑：props/emits/状态流/轮询/命令调用一律不动；仅调整模板包装结构与样式。
- 不加遥测；不提交 git；不触碰 A-05 观察窗口与归档。
- 金额/费率/数量在前端始终为字符串展示，不引入浮点计算（Decimal 语义不变）。

## 5. 变更面

- `src/style.css`：重构为 CSS 变量设计令牌 + 统一组件类（视觉主体集中于此文件，已全量阅读）。
- `src/components/*.vue`（15 个）：字号/间距/内联样式/图标/包装结构按令牌体系调整；`SidebarNav.vue` scoped 样式同步。
- `src/glossary.ts`（R11 新增）：名词→中文解释词条表，约 98 条，覆盖控制台名词字段（机会指标、验证报告 B01–B04 标签、回放统计、重连指标）与设置页全部配置字段英文 key。
- `src/components/TermHint.vue`（R11 新增）：`el-tooltip` 悬浮组件，`term` prop 查词条表，未收录渲染纯文本；接入方式为表格列头 `#header` 插槽、表单 label 内嵌、指标/报告标签包裹，不包裹表单控件。
- `src-tauri/tauri.conf.json`：仅窗口 width/height/minWidth/minHeight 四项。
- 文档：`docs/UI-01-前端视觉优化-设计.md`（设计评审产物）、AIDLC 手册发布记录（发布阶段产物）。
- 不改：`src/types.ts`、`src/commands.ts`（无契约变化）、后端全部。

## 6. 风险与失败关闭

- 风险：改动面 15 组件 × 全局样式；构建门禁兜底类型错误；视觉主观 → 设计令牌先行、统一生效。
- 失败关闭：`npm run build` 报错即停；每页改动后浏览器目检；任何与后端交互的异常（调用失败、数据缺失）即回查。
- 未满足 UI-01-R09 / R10 不进入发布记录。
