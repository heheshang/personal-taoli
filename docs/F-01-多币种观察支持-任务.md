## 2. 必须通过的行为

1. 配置仅以 `pairs: Vec<PairConfig>` 为交易对真相源，无单数字段残留；旧格式（顶层 `symbol`）加载自动迁移为单元素列表。
2. 每个币种独立完成「账户/品种加载 → 双所订单簿订阅 → VALID 等待 → 扫描 → 带 symbol 事件落归档」，币种间互不干扰。
3. 连续观察中单币种 feed 失效只产生该币种健康事件，其余币种继续 VALID 扫描。
4. 归档事件 `DecisionEvent` 序列化结构不变（SCHEMA_VERSION=1），旧单币种归档可回放。
5. 桌面端按币种展示配置与扫描报告；设置页可编辑币种列表。
