# UI-01 前端视觉优化：设计文档

文档状态：`released`（所有者 2026-09-09 发布签收）。
需求依据：`docs/UI-01-前端视觉优化-需求.md`（所有者 2026-09-09 确认）。

## 1. 设计原则

- 保留 C-01 遗留的浅色绿灰金融基调与「只读 / 安全」语义，不推倒重来。
- 精致化手段：统一设计令牌（CSS 变量）、清晰信息层级、充足留白、语义状态色、轻微交互反馈。
- 中文正文用无衬线系统字体栈；数字 / 金额 / 代码 / JSON 用等宽字体，tabular 对齐。
- 零新依赖；全部视觉落在 `src/style.css` 令牌与组件 class，组件逻辑零改动。

### 4.1 名词悬浮解释（R11）

- **词条表 `src/glossary.ts`**：扁平 `Record<string, string>`，约 98 条。键同时覆盖两类名词：设置页配置字段英文 key（`database_url`、`binance_api_key`、全部 `_ms` 时序字段、strategy 六字段等）与中文名词（机会指标、B01–B04 验证报告标签、回放统计、重连指标、ShadowReport 字段）。全表字符串值，无嵌套结构。
- **组件 `src/components/TermHint.vue`**：`props: { term: string }`，computed 从 `GLOSSARY` 查解释。命中 → `<el-tooltip :content="hint" placement="top" :show-after="80"><span class="term-hint">…</span></el-tooltip>`；未命中 → `<span class="term-plain">…</span>`，无 tooltip、不破坏布局。`el-tooltip` 经 `main.ts` 全局注册 Element Plus 直接可用，零新依赖。
- **接入方式（三种，均不包裹表单控件）**：
  1. 表格列头：`ElTableColumn` 用 `#header` 插槽包 `<TermHint>`（`label` 属性是 string，放不下组件）；
  2. 表单字段：label 文本内嵌 `<TermHint>`（`el-tooltip` 包裹控件会连带渲染表单结构，禁用）；
  3. 指标/报告标签：`<small>` / `<label>` 内包 `<TermHint>`。
- **覆盖范围**：DetailPanel（机会卡六指标、账号表三表头、验证报告动态字段 `formatKey` 结果、ShadowReport 概览与 P50/P95、重连四指标）、SettingsPage 全部字段、概览/市场小面板（MetricGrid/RidgePanel/StrategyLattice/VenueHandoff/ConfigStrip）。
- **样式**：`.term-hint { border-bottom: 1px dashed var(--text-3); cursor: help; }`，随全局令牌，不改字号不挤行高。

## 5. Element Plus 主题对齐（CSS 变量覆盖，无需重编译）

- `--el-color-primary` 系列 → accent（light-3/5/7/8/9 与 dark-2 全对齐）。
- `--el-border-radius-base: 6px`；`--el-font-size-base: 12px`。
- 按钮：class 覆盖 min-height 32px / padding；输入框、switch、tag 随主题色。

## 6. 装饰图形方案（保留，精致化）

- 雷达图：同心椭圆 1.5px teal 系描边 + 扫描线 lime→amber 渐变；加极淡径向渐变底。
- 山脊线：线宽 2px，绿→粉渐变分层保留，整体透明度层级保留；下方轻辉光。
- 立方体：六面描边收敛为 accent 蓝绿与语义两色组合；加柔投影。
- 关系图：radial 渐变底保留；节点白底、描边 accent（中心节点 info），虚线流加深。
- 共性：统一卡片圆角 10px、shadow-1、hover 边框 accent-soft。
