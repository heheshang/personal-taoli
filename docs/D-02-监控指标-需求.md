# D-02 监控指标：需求文档

文档状态：`in_progress`。本阶段实现系统监控指标收集能力。

## 1. 目标

建立系统监控指标收集能力，支持Prometheus格式指标暴露。

## 2. 需求

| 编号 | 要求 | 验收结果 |
|---|---|---|
| D02-R01 | 支持多种指标类型（Counter, Gauge, Histogram, Summary） | 指标类型定义完整 |
| D02-R02 | 支持系统指标收集 | 系统指标功能完整 |
| D02-R03 | 支持交易指标收集 | 交易指标功能完整 |
| D02-R04 | 支持市场指标收集 | 市场指标功能完整 |
| D02-R05 | 支持风险指标收集 | 风险指标功能完整 |
| D02-R06 | 指标可查询和导出 | 指标查询功能完整 |

## 3. 明确不做

- 不接入真实交易所进行监控测试。
- 不修改生产环境配置。
- 不执行真实监控（仅模拟）。
- 不影响系统正常运行。

## 4. 验证边界

```text
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
npm run build
cargo build --workspace --release
```

监控指标模块必须覆盖所有预定义指标类型，每个测试必须有明确的预期行为和结果验证。
