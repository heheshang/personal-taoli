# G-01 模拟套利仪表盘（独立页面）：需求文档

文档状态：立项（2026-09-09）。立项编号为 **G-01**（阶段 F/G 模拟套利可视化迭代）：F-03 编号在 F-02 文档与手册中已被预绑定「生产部署 / 真实接入评估」语义，不占用；本迭代为 F-02 模拟套利引擎的 GUI 展示层，按 F-02 需求文档预留的独立编号（如 G-01）立项，仅影响文档命名与发布记录，与 AIDLC 手册 §11 无冲突。

本迭代在 F-02 仿真执行闭环（真实行情 → 决策 → 模拟撮合 → PAPER 事实落库 → 仿真报告）之上，新增**独立的「模拟套利」页面**：模拟真实场景，展示交易细节与获利多少、曲线图、流转图、余额 / 机会历史、活动日志、套利机会山脊图，以及**两个账户（每 run 买腿账户与卖腿账户）的详情与变化图**。**全程只读展示**：页面与查询层不产生任何新的写路径，`external_order_calls=0` 恒真保持（AIDLC §2 安全边界）。

## 1. 目标

F-02 交付后，模拟执行数据全部落库（execution_plans / order_intents / order_facts / trade_facts / execution_facts / execution_events / fund_reservations / risk_decisions / audit_events / paper_balances / ledger_*），但桌面端仅有控制台页的一个烟测入口与探针报告网格，没有任何页面呈现产出。本迭代：

1. 新增侧栏独立页「模拟套利」；
2. 为页面提供后端只读查询能力（机会历史 / run 详情 / 余额 / 活动日志 / 山脊图数据），数据来自既有 PAPER 事实层 + 一张新增的 run 报告投影表；
3. 补齐两处持久化缺口：F-02 未落库的**报告专属值**（scenario、净盈亏、滑点 bps、时延采样、补偿估额等）与**余额历史点**（当前 `balance_snapshots` 仅对账时写入，模拟 run 不拍点），页面所需数据因此可信；
4. 全部图表手写 SVG（仓库无图表库，沿用 HistoryChart/RidgePanel 视觉风格），不引入第三方依赖。

核心原则（不可丢弃）：**展示层只读**——查询走独立读模块，不碰领域单写者锁，不新增任何写/下单路径；**报告专属值投影为只读冗余**，事实单一真相源始终是既有 PAPER fact 表；**全程 `Decimal`**，禁止转浮点。

## 3. 明确不做

- 不接入真实或测试网订单；`external_order_calls=0` 恒真；不解除 A-05 影子窗口。
- 不新增模拟配置编辑 UI（配置仍来自 `observer.{toml,json}`，页面只读展示当前配置摘要）；不改 `ObserverConfig.simulation` 任何字段语义。
- 不改变撮合引擎语义：`simulate_leg` / 成交价模型（D2）/ 时延采样（D3）/ 连续模式（D4）/ 补偿（D7）任何决策不改；引擎代码仅新增「报告落库 + 余额快照」两个无害钩子。
- 不动 observer 生命周期：连续模拟的启动/停止仍在控制台页操作；本页面仅提供展示 + 「运行一次烟测」按钮（复用 `run_simulation_smoke_command`）。
- 不引入第三方图表库（echarts 等）：全部 SVG 手写，沿用 UI-01 视觉体系。
- 不在本迭代做历史 run 的清理/释放（PAPER `LOCAL_RESERVED` / `RESERVED` 累积的运维成本事后计费任务另行立项，设计文档风险表记录）。
- 不拟合真实概率分布、不做 K 线回测、不做跨 run 资金共享、不改变既有 0001–0004 迁移的内容（MIG-01 只剥离了各文件尾部的记账语句，见该迭代文档）。
- 数据库只读查询不经领域单写者锁（`DomainConnection::acquire`），避免读路径竞争写路径。
