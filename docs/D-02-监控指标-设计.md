# D-02 监控指标：设计文档

文档状态：`in_progress`。实现监控指标模块。

## 1. 模块边界

- `crates/core/src/metrics.rs`：监控指标核心模块，包含指标类型、收集器和各类指标。

## 2. 指标类型

| 类型 | 描述 | 使用场景 |
|---|---|---|
| Counter | 计数器 | 累计值，如订单数量、成交数量 |
| Gauge | 仪表盘 | 可增可减的值，如内存使用、CPU使用 |
| Histogram | 直方图 | 值分布，如延迟、耗时 |
| Summary | 摘要 | 值统计，如分位数 |

## 3. 指标收集器设计

```text
MetricsCollector {
    metrics: Arc<RwLock<HashMap<String, Metric>>>,
}

impl MetricsCollector {
    pub fn new() -> Self;
    pub async fn record_counter(&self, name: &str, value: i64, labels: HashMap<String, String>);
    pub async fn record_gauge(&self, name: &str, value: f64, labels: HashMap<String, String>);
    pub async fn record_histogram(&self, name: &str, value: f64, labels: HashMap<String, String>);
    pub async fn get_metrics(&self) -> HashMap<String, Metric>;
    pub async fn get_metric(&self, name: &str) -> Option<Metric>;
    pub async fn clear_metrics(&self);
}
```

## 8. 失败关闭

- 指标收集必须支持异步操作。
- 指标查询必须支持标签过滤。
- 指标导出必须支持Prometheus格式。
- 所有测试必须在隔离环境运行，不影响生产环境。

## 9. 接入命令

监控指标可通过以下方式使用：

```text
// 创建收集器
let collector = Arc::new(MetricsCollector::new());

// 记录指标
let system_metrics = SystemMetrics::new(collector.clone());
system_metrics.record_uptime(3600).await;

// 查询指标
let metrics = collector.get_metrics().await;
```

## 10. 发布限制

监控指标模块只用于隔离环境验证，不影响生产环境配置和运行。真实监控需要独立的需求和审批流程。
