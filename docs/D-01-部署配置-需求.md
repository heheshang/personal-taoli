# D-01 部署配置：需求文档

文档状态：`in_progress`。本阶段实现系统部署配置能力。

## 1. 目标

建立可重复的系统部署能力，支持单机部署和运维。

## 2. 需求

| 编号 | 要求 | 验收结果 |
|---|---|---|
| D01-R01 | 支持Docker Compose部署 | Docker Compose配置完整 |
| D01-R02 | 支持systemd部署 | systemd配置完整 |
| D01-R03 | 支持环境变量配置 | 环境变量配置完整 |
| D01-R04 | 支持配置文件管理 | 配置文件管理完整 |
| D01-R05 | 支持健康检查 | 健康检查功能完整 |
| D01-R06 | 支持优雅停止 | 优雅停止功能完整 |

## 3. 明确不做

- 不接入真实交易所进行部署测试。
- 不修改生产环境配置。
- 不执行真实部署（仅配置）。
- 不影响系统正常运行。

## 4. 验证边界

```text
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
npm run build
cargo build --workspace --release
docker-compose config
```

部署配置必须覆盖所有预定义部署场景，每个配置必须有明确的验证和测试。
