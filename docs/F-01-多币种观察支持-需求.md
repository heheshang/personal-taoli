# F-01 多币种观察支持：需求文档

文档状态：开发中（2026-09-09 立项，所有者确认「完整多币种架构」）。本迭代把单币种观察架构升级为多币种并行观察架构。

## 1. 目标

当前 `ObserverConfig` 为单一交易对（`symbol`/`base_asset`/`quote_asset`/`quantity` 各一值），`observe_once`、`observe_continuously`、`run_reconnect_smoke` 三个入口均只观察一个币种。本迭代改为多币种架构：配置持有一个币种列表，连续观察对**每个币种各自独立**建立两所订单簿订阅并按对扫描，决策事件/扫描报告带各自 `symbol` 落归档，桌面端按币种展示。保持只读观察，不引入真实下单能力。

## 2. 需求

| 编号 | 要求 | 验收结果 |
|---|---|---|
| F01-R01 | 配置从单一 `symbol` 字段**彻底**升级为币种列表：删除 `symbol`/`base_asset`/`quote_asset`/`quantity` 单数字段，`pairs: Vec<PairConfig>` 为唯一真相源；每个币种条目携带 `symbol`/`base_asset`/`quote_asset`/`quantity`；新建/加载/校验/保存全链路支持列表；旧单币种配置加载时自动迁移为单元素列表 | `ObserverConfig` 仅暴露 `pairs` 列表（无单数字段残留）；TOML 与 JSON 加载（含旧格式迁移）、`save_to_json`、`default_config`、`validate` 通过 |
| F01-R02 | `observe_once` 对配置中的每个币种独立执行完整单次观察：分别加载双方品种规格、校验 pair、订阅两所订单簿、等待双书 VALID、扫描并落归档 | 一次调用产出每币种各自的报告、账户数据、feed 状态与归档；币种间不互相干扰 |
| F01-R03 | `observe_continuously` 对每个币种独立维护两所订单簿 feed 并逐对扫描：每币种各自的 scan 轮询与账户刷新，决策事件/健康事件带各自 `symbol` 落归档 | 连续运行中每币种独立产生带 `symbol` 的事件；单币种 feed 失效只影响该币种（健康事件），其余币种继续 VALID 扫描 |
| F01-R04 | `run_reconnect_smoke` 覆盖每个配置币种的重连恢复验证，报告带 `symbol` | 每币种强制重连后双 feed 在新代次恢复，结果按币种独立报告 |
| F01-R05 | 归档中 `DecisionEvent`/`ScanReport`/`DecisionConfig` 正确携带各自 `symbol`，查询/回放可按币种区分 | `ArchivedEvent` 序列化含正确 `symbol`；`replay_archive` 对多币种混合归档逐条还原各自 symbol |
| F01-R06 | 桌面端按币种展示：概览/控制台展示配置的币种列表、连续观察状态与最近报告按币种标识、报告内 symbol 正确渲染；设置页可编辑多条币种记录 | 前端类型与绑定升级后 `npm run build` 零错误；浏览器页面展示币种列表；单币种兼容展示不退化 |
| F01-R07 | 保持只读边界：不接入真实账户能力、不引入任何真实下单路径，`external_order_calls=0` 约束不变 | 需求/设计与 AIDLC 运行边界一致；无新增真实下单代码 |
| F01-R08 | 测试可追溯：多币种行为有确定性测试覆盖（配置迁移、逐币种扫描独立、事件 symbol 正确） | `cargo test --workspace` 全绿（基线 173 项前）；`cargo clippy --workspace --all-targets -- -D warnings` 零警告；`cargo fmt --all -- --check` 通过 |

## 3. 明确不做

- 不接入真实账户、真实行情之外的扩展能力；真实接入属阶段 F 之后，不属本迭代。
- 不引入任何真实下单能力；`external_order_calls=0` 约束不变。
- 不重写扫描/行情/归档核心算法；`scan_pair`/venue 层已按 symbol 参数化，直接复用。
- 不触碰 A-05 正式归档（`data/archive/a05-shadow-20260908.ndjson`）与 A-05 观察窗口语义。
- 不做多币种间价差（例如 BTC/ETH 相对价差），只做「每币种两所间」价差，与现状一致。
- 不改变策略参数语义；策略参数（min_net_profit 等）保持全局配置。
