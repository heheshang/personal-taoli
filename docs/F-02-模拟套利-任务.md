# F-02 模拟套利（真实场景仿真执行）：任务文档

文档状态：开发中（2026-09-09）。实现顺序与验收见需求/设计文档；本文件为文件级执行清单。

## 1. 实现顺序

### 1.1 核心：config.rs

- 文件：`crates/core/src/config.rs`
- 新增 `#[derive(Debug, Clone, Serialize, Deserialize)] #[serde(default)] pub struct SimulationConfig`（字段见设计 §3），含 `impl Default`、`validate() -> Result<()>`：
  - `decision_to_submit_ms_min <= max`、`fill_latency_ms_min <= max`
  - `adverse_move_bps`/`competitor_take_bps`/`unknown_submit_probability_bps`/`query_found_probability_bps`/`compensation_markup_bps` ∈ [0, 10000]
  - `initial_quote_balance > 0`、`initial_base_balance > 0`
  - `max_unmatched_exposure >= 0`、`compensation_budget >= 0`
- `ObserverConfig` 增 `pub simulation: SimulationConfig` 字段（`#[serde(default)]` 保证旧配置/fixture 无 `[simulation]` 仍可加载）；`ObserverConfig::validate` 调 `self.simulation.validate()?`。

### 1.2 核心：simulation.rs（新增）

模块声明加入 `crates/core/src/lib.rs`（`mod simulation;`，并 `pub use` 公开类型）。内容：

- `SimRng`：splitmix64（`next_u64`/`gen_range_u64(min,max)`/`gen_unit_bps(0..=10000)`），`new(seed)`；`#[test]` 断言同 seed 序列一致、不同 seed 不同、边界闭合。
- `simulate_leg(side: BookSide, book: &OrderBookSnapshot, requested: Decimal, config: &SimulationConfig, rng: &mut SimRng) -> SimLegResult`：
  - 逐档消费：`effective = level_qty × (1 − competitor_take_bps/10000)`，按 `quantity_step` 圆整为消费步进；
  - 档价 × adverse 偏移（买侧加、卖侧减）；
  - 返回 `{ filled, avg_price, depth_shortfall, last_raw_price }`（`last_raw_price` = 最后消费档偏移前的档价，供滑点对比）。
  - 语义：深度不足 → 部分成交 + `depth_shortfall`；首档有效量为 0 或簿为空 → filled=0。
- `async fn run_simulation_run(database_url, event: &DecisionEvent, direction_index, config, seed) -> Result<SimulationRunReport>`：
  - 命名空间构造（设计 §2）；
  - `set_paper_balance ×2`（买腿 venue/quote 资产、卖腿 venue/base 资产）；
  - `PaperCore::reserve_plan`（失败 → 返回 `Rejected` 报告而非整体 bail，记录原因）；
  - `ExecutionCore::initialize_plan`；
  - `OrderCore`：`ensure_intent`×2 → `submit_started`×2 → `submit_result`（按 UNKNOWN 概率分支到 `Unknown`，查询按 `query_found_probability_bps` 分支 `Found/NotFound`）→ 每条腿 `simulate_leg` 撮合 → `record_trade`（trade_id 幂等）；
  - `ExecutionCore::evaluate(plan_id, leg_a_filled, leg_b_filled, exposure_per_unit, compensation_cost_per_unit)`；
  - 组装 `SimulationRunReport`（全部 `Decimal` 保留精度）；
  - run 结束后 `disconnect()` 全部 core。
- `pub async fn run_simulation_smoke(database_url: &str) -> Result<SimulationSmokeReport>`：`migrate` 开头，按需求 §4.2 S01–S09 合成簿场景逐一执行（合成 `DecisionEvent`/`OrderBookSnapshot`/`InstrumentSpec` 直接构造），断言输出布尔 + `external_order_calls: 0`；任一断言失败 `bail!`（B 系列范式）。
- `#[cfg(test)]` 纯逻辑测试：撮合分支（正常/短fall/全占/圆整/min_quantity）、RNG 确定性、config validate 边界。

### 1.3 核心：observer.rs（连续模式接入）

- `observe_continuously` 签名不变；内部新增：若 `config.simulation.enabled`，构造 `SimulationBridge`（mpsc + tokio task）；
- 每 pair `scan_current` + `on_report` 之后：`bridge.offer(event)`（克隆入队；积压跳帧在消费者侧：消费前 drain 旧事件只留最新）；
- 桥持有 `database_url`（配置缺失 → 告警 + 不启动，观察主循环不受影响）；
- 引擎错误仅记录，不传播出循环。
