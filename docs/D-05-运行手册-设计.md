# D-05 运行手册：设计文档

文档状态：`in_progress`。实现运行手册管理模块。

## 1. 模块边界

- `crates/core/src/runbook_manager.rs`：运行手册管理核心模块，包含手册创建、管理和搜索。

## 2. 运行手册结构

```text
Runbook {
    runbook_id: String,
    title: String,
    description: String,
    version: String,
    sections: Vec<RunbookSection>,
    tags: HashMap<String, String>,
    created_at_ms: u64,
    updated_at_ms: u64,
}

RunbookSection {
    section_id: String,
    title: String,
    content: String,
    order: u32,
    subsections: Vec<RunbookSection>,
}
```

## 3. 运行手册管理器设计

```text
RunbookManager {
    runbooks: HashMap<String, Runbook>,
}

impl RunbookManager {
    pub fn new() -> Self;
    pub fn add_runbook(&mut self, runbook: Runbook);
    pub fn get_runbook(&self, runbook_id: &str) -> Option<&Runbook>;
    pub fn get_runbooks(&self) -> &HashMap<String, Runbook>;
    pub fn delete_runbook(&mut self, runbook_id: &str) -> Result<()>;
    pub fn update_runbook(&mut self, runbook: Runbook) -> Result<()>;
    pub fn search_runbooks(&self, query: &str) -> Vec<&Runbook>;
    pub fn get_runbooks_by_tag(&self, key: &str, value: &str) -> Vec<&Runbook>;
}
```

## 6. 失败关闭

- 运行手册必须包含完整章节。
- 运行手册管理必须支持CRUD操作。
- 运行手册搜索必须支持全文搜索。
- 所有测试必须在隔离环境运行，不影响生产环境。

## 7. 接入命令

运行手册管理器可通过以下方式使用：

```text
// 创建管理器
let mut manager = RunbookManager::new();

// 添加手册
let runbook = RunbookTemplate::system_startup();
manager.add_runbook(runbook);

// 搜索手册
let results = manager.search_runbooks("startup");

// 获取手册
let runbook = manager.get_runbook("system-startup");
```

## 8. 发布限制

运行手册模块只用于隔离环境验证，不影响生产环境配置和运行。真实运行手册需要独立的需求和审批流程。
