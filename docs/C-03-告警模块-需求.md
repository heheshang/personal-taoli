# C-03 告警模块：需求文档

文档状态：`in_progress`。本阶段实现系统监控和告警功能。

## 1. 目标

建立系统监控和告警能力，及时发现和处理系统异常。

## 2. 需求

| 编号 | 要求 | 验收结果 |
|---|---|---|
| C03-R01 | 支持多种告警级别（Critical, High, Medium, Info） | 告警级别定义完整 |
| C03-R02 | 支持多种告警类型（私有流中断、裸露敞口、未知订单等） | 告警类型定义完整 |
| C03-R03 | 告警状态可管理（Pending, Acknowledged, Resolved, Ignored） | 告警状态管理功能完整 |
| C03-R04 | 告警可确认、解决、忽略 | 告警操作功能完整 |
| C03-R05 | 告警可按级别和状态过滤查询 | 告警查询功能完整 |
| C03-R06 | 告警通知可扩展（支持控制台、日志等） | 通知器trait定义完整 |

## 3. 明确不做

- 不接入真实交易所进行告警测试。
- 不修改生产环境配置。
- 不执行真实告警通知（仅模拟）。
- 不影响系统正常运行。

## 4. 验证边界

```text
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
npm run build
cargo build --workspace --release
```

告警模块必须覆盖所有预定义告警级别和类型，每个测试必须有明确的预期行为和结果验证。
