# E-03 运维操作：设计文档

文档状态：`released`（所有者 2026-09-09 发布签收）。实现运维操作模块。

## 1. 模块边界

- `crates/core/src/operations.rs`：运维操作核心模块，包含操作创建、执行和状态管理。

## 2. 运维操作类型

| 类型 | 描述 | 使用场景 |
|---|---|---|
| SystemStartup | 系统启动 | 系统初始化 |
| SystemShutdown | 系统关闭 | 系统停止 |
| ConfigUpdate | 配置更新 | 配置变更 |
| DatabaseMaintenance | 数据库维护 | 数据库维护 |
| LogCleanup | 日志清理 | 日志管理 |
| BackupRestore | 备份恢复 | 数据恢复 |

## 3. 运维操作状态

```text
Pending -> Running -> Completed
```

## 4. 运维操作管理器设计

```text
OperationManager {
    operations: Arc<RwLock<HashMap<String, Operation>>>,
}

impl OperationManager {
    pub fn new() -> Self;
    pub async fn create_operation(&self, operation_type: OperationType, description: String, parameters: HashMap<String, String>, now_ms: u64) -> Operation;
    pub async fn start_operation(&self, operation_id: &str, now_ms: u64) -> Result<Operation>;
    pub async fn complete_operation(&self, operation_id: &str, now_ms: u64) -> Result<Operation>;
    pub async fn fail_operation(&self, operation_id: &str, error_message: &str) -> Result<Operation>;
    pub async fn cancel_operation(&self, operation_id: &str) -> Result<Operation>;
    pub async fn get_operations(&self) -> Vec<Operation>;
    pub async fn get_operations_by_status(&self, status: &OperationStatus) -> Vec<Operation>;
    pub async fn clear_operations(&self);
}
```

## 6. 失败关闭

- 运维操作创建必须包含完整信息。
- 运维操作状态变更必须记录时间戳。
- 运维操作查询必须支持按状态过滤。
- 所有测试必须在隔离环境运行，不影响生产环境。

## 7. 接入命令

运维操作管理器可通过以下方式使用：

```text
// 创建管理器
let manager = OperationManager::new();

// 创建运维操作
let mut parameters = HashMap::new();
parameters.insert("key".to_string(), "value".to_string());
let operation = manager.create_operation(
    OperationType::SystemStartup,
    "System startup operation".to_string(),
    parameters,
    1000,
).await;

// 开始执行
manager.start_operation(&operation.operation_id, 2000).await?;

// 完成执行
manager.complete_operation(&operation.operation_id, 3000).await?;
```
