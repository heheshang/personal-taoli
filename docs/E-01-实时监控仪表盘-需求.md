# E-01 实时监控仪表盘：需求文档

文档状态：`in_progress`。本阶段实现实时监控仪表盘能力。

## 1. 目标

建立实时监控仪表盘能力，支持系统状态可视化。

## 2. 需求

| 编号 | 要求 | 验收结果 |
|---|---|---|
| E01-R01 | 支持系统状态实时监控 | 系统状态监控功能完整 |
| E01-R02 | 支持交易状态实时监控 | 交易状态监控功能完整 |
| E01-R03 | 支持市场状态实时监控 | 市场状态监控功能完整 |
| E01-R04 | 支持风险状态实时监控 | 风险状态监控功能完整 |
| E01-R05 | 支持仪表盘数据导出 | 仪表盘数据导出功能完整 |
| E01-R06 | 测试结果可追溯 | 生成结构化测试报告 |

## 3. 明确不做

- 不接入真实交易所进行监控测试。
- 不修改生产环境配置。
- 不执行真实监控（仅模拟）。
- 不影响系统正常运行。

## 4. 验证边界

```text
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
npm run build
cargo build --workspace --release
```

实时监控仪表盘测试套件必须覆盖所有预定义测试场景，每个测试必须有明确的预期行为和结果验证。
