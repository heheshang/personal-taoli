# E-04 系统健康检查：设计文档

文档状态：`in_progress`。实现系统健康检查模块。

## 1. 模块边界

- `crates/core/src/system_health.rs`：系统健康检查核心模块，包含健康检查执行和历史记录。

## 2. 健康状态

| 状态 | 描述 | 处置 |
|---|---|---|
| Healthy | 健康 | 系统正常运行 |
| Unhealthy | 不健康 | 需要立即处理 |
| Degraded | 降级 | 降级运行 |

## 3. 健康检查项

| 检查项 | 描述 | 检查内容 |
|---|---|---|
| database | 数据库连接 | 数据库连接状态 |
| memory | 内存使用 | 内存使用率 |
| disk | 磁盘空间 | 磁盘使用率 |
| cpu | CPU使用 | CPU使用率 |

## 4. 系统健康检查器设计

```text
SystemHealthChecker {
    results: Arc<RwLock<Vec<HealthCheckResult>>>,
}

impl SystemHealthChecker {
    pub fn new() -> Self;
    pub async fn check_health(&self) -> HealthCheckResult;
    pub async fn get_results(&self) -> Vec<HealthCheckResult>;
    pub async fn get_latest_result(&self) -> Option<HealthCheckResult>;
    pub async fn clear_results(&self);
}
```

## 6. 失败关闭

- 健康检查必须包含完整检查项。
- 健康检查历史必须支持查询。
- 健康检查状态必须支持管理。
- 所有测试必须在隔离环境运行，不影响生产环境。

## 7. 接入命令

系统健康检查器可通过以下方式使用：

```text
// 创建检查器
let checker = SystemHealthChecker::new();

// 执行健康检查
let result = checker.check_health().await;
assert_eq!(result.status, HealthStatus::Healthy);

// 获取历史
let results = checker.get_results().await;

// 获取最新结果
let latest = checker.get_latest_result().await;
```

## 8. 发布限制

系统健康检查模块只用于隔离环境验证，不影响生产环境配置和运行。真实系统健康检查需要独立的需求和审批流程。
