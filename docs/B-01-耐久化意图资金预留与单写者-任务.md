## 4. 必须通过的行为

1. 同域只有一个数据库会话取得写资格；原会话关闭后新会话才能取得。
2. 一个计划写入后，计划、风险决定、两腿意图、资金预留和审计同时可恢复。
3. 余额不足不会留下计划、意图、预留或审计残片。
4. 两个不同品种并发争抢相同 PAPER 余额时只能有一个成功。
5. 同请求重试返回原计划；同 ID 改内容被拒绝。
6. 重连恢复时资金仍预留、意图仍为 `NOT_SENT`，不会自动发送。
7. 现有 `observe_once` 与连续观察会话仍只访问公共行情和可选只读账户元数据，程序没有下单 API。
