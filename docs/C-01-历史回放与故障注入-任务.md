## 2. 必须通过的行为

1. 故障注入器必须支持启用/禁用控制。
2. 丢包和重复故障必须基于配置概率触发。
3. 断线、崩溃和数据库失效必须支持外部触发。
4. 测试套件必须覆盖所有预定义故障类型。
5. 每个测试必须有明确的预期行为和结果验证。
6. 测试结果必须包含恢复检测和数据完整性验证。
7. 所有测试必须在隔离环境运行，不影响生产环境。
