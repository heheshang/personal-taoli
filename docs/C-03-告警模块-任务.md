## 2. 必须通过的行为

1. 告警级别必须支持Critical、High、Medium、Info。
2. 告警类型必须支持私有流中断、裸露敞口、未知订单等。
3. 告警状态必须支持Pending、Acknowledged、Resolved、Ignored。
4. 告警管理器必须支持创建、确认、解决、忽略操作。
5. 告警查询必须支持按级别和状态过滤。
6. 告警通知必须支持异步扩展。
