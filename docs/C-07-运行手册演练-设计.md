# C-07 运行手册演练：设计文档

文档状态：`in_progress`。实现运行手册演练模块。

## 1. 模块边界

- `crates/core/src/runbook.rs`：运行手册演练核心模块，包含演练场景、步骤和结果管理。

## 2. 演练场景

| 场景 | 描述 | 步骤数 |
|---|---|---|
| SystemStartup | 系统启动演练 | 3 |
| SystemShutdown | 系统关闭演练 | 3 |
| FaultRecovery | 故障恢复演练 | 3 |
| DatabaseRecovery | 数据库恢复演练 | 3 |
| ConfigUpdate | 配置更新演练 | 3 |
| LogCleanup | 日志清理演练 | 3 |

## 3. 演练步骤状态

```text
Pending -> InProgress -> Passed
                 |
                 v
               Failed
                 |
                 v
              Skipped
```

## 4. 演练管理器设计

```text
RunbookDrillManager {
    scenarios: Vec<DrillScenario>,
    results: Vec<DrillResult>,
}

impl RunbookDrillManager {
    pub fn new() -> Self;
    pub fn add_scenario(&mut self, scenario: DrillScenario);
    pub async fn execute_drill(&mut self, scenario: &DrillScenario, now_ms: u64) -> DrillResult;
    pub fn get_results(&self) -> &[DrillResult];
    pub fn get_latest_result(&self) -> Option<&DrillResult>;
    pub fn all_drills_passed(&self) -> bool;
}
```

## 5. 演练结果结构

```text
DrillResult {
    scenario: DrillScenario,
    steps: Vec<DrillStep>,
    passed: bool,
    started_at_ms: u64,
    completed_at_ms: u64,
    duration_ms: u64,
    error_message: Option<String>,
}
```


## 7. 失败关闭

- 演练场景必须包含完整步骤定义。
- 演练步骤必须包含预期结果。
- 演练结果必须记录实际结果。
- 所有测试必须在隔离环境运行，不影响生产环境。

## 8. 接入命令

运行手册演练管理器可通过以下方式调用：

```text
// 创建管理器
let mut manager = RunbookDrillManager::new();

// 添加场景
manager.add_scenario(DrillScenario::SystemStartup);

// 执行演练
let result = manager.execute_drill(&DrillScenario::SystemStartup, 1000).await;

// 检查结果
if result.passed {
    println!("演练通过");
}
```

## 9. 发布限制

运行手册演练模块只用于隔离环境验证，不影响生产环境配置和运行。真实运行手册演练需要独立的需求和审批流程。
