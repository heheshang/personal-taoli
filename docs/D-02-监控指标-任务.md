## 2. 必须通过的行为

1. 指标类型必须支持Counter、Gauge、Histogram、Summary。
2. 指标收集器必须支持异步操作。
3. 系统指标必须支持启动时间、运行时间、内存、CPU、磁盘。
4. 交易指标必须支持订单数量、成交数量、延迟、收益。
5. 市场指标必须支持行情延迟、断档、深度。
6. 风险指标必须支持敞口、保证金使用率、事件。
