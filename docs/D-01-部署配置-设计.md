# D-01 部署配置：设计文档

文档状态：`in_progress`。实现部署配置模块。

## 1. 模块边界

- `deploy/`：部署配置目录，包含Docker Compose、systemd和环境变量配置。

## 2. 部署方式

| 方式 | 描述 | 使用场景 |
|---|---|---|
| Docker Compose | 容器化部署 | 开发和测试环境 |
| systemd | 系统服务部署 | 生产环境 |

## 3. 环境变量配置

| 变量 | 描述 | 默认值 |
|---|---|---|
| DATABASE_URL | 数据库连接字符串 | postgresql://localhost:5432/taoli |
| RUST_LOG | 日志级别 | info |
| TAOLI_MODE | 运行模式 | observe |
| TAOLI_CONFIG_PATH | 配置文件路径 | ./config.toml |

## 4. Docker Compose配置

```yaml
version: '3.8'
services:
  taoli-core:
    build: .
    ports:
      - "8080:8080"
    environment:
      - DATABASE_URL=${DATABASE_URL}
      - RUST_LOG=${RUST_LOG}
    volumes:
      - ./config:/app/config
      - ./data:/app/data
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/health"]
      interval: 30s
      timeout: 10s
      retries: 3
    restart: unless-stopped
```

## 5. systemd配置

```ini
[Unit]
Description=Taoli Trading Core
After=network.target postgresql.service

[Service]
Type=simple
User=taoli
WorkingDirectory=/opt/taoli
ExecStart=/opt/taoli/taoli-core
Restart=on-failure
RestartSec=5
Environment=RUST_LOG=info
Environment=DATABASE_URL=postgresql://localhost:5432/taoli

[Install]
WantedBy=multi-user.target
```

## 8. 失败关闭

- 部署配置必须包含完整的环境变量。
- 健康检查必须支持超时配置。
- 优雅停止必须支持超时配置。
- 所有配置必须在隔离环境验证，不影响生产环境。

## 9. 接入命令

部署配置可通过以下方式使用：

```text
// 使用Docker Compose部署
docker-compose up -d

// 使用systemd部署
sudo systemctl start taoli-core

// 健康检查
curl http://localhost:8080/health

// 优雅停止
kill -SIGTERM <pid>
```

## 10. 发布限制

部署配置只用于隔离环境验证，不影响生产环境配置和运行。真实部署需要独立的需求和审批流程。
