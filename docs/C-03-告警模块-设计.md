# C-03 告警模块：设计文档

文档状态：`in_progress`。实现告警模块。

## 1. 模块边界

- `crates/core/src/alert.rs`：告警核心模块，包含告警级别、类型、状态定义和告警管理器。

## 2. 告警级别

| 级别 | 描述 | 处置 |
|---|---|---|
| Critical | P0: 无法确认的大额敞口、保证金危险、交易核心失联且有仓位、持久化失效 | 立即推送到至少两个独立通道；人工从原生交易终端接管 |
| High | P1: 未知订单超时、私有流中断、余额冲突、持续单场所故障 | 阻断对应新交易并尽快处理 |
| Medium | P2: 库存偏移、行情延迟升高、归档积压、收益估计误差变大 | 降级或计划处理 |
| Info | 信息: 正常启停、配置批准、日结、再平衡到账 | 保留审计，避免通知噪声 |

## 3. 告警类型

| 类型 | 描述 | 相关数据 |
|---|---|---|
| PrivateStream中断 | 私有流中断 | venue, duration_ms |
| Exposure | 裸露敞口 | amount, duration_ms |
| UnknownOrder | 未知订单 | venue, order_id, timeout_ms |
| BalanceConflict | 余额冲突 | venue, asset, local_amount, external_amount |
| DatabaseFailure | 数据库失效 | duration_ms |
| ProcessCrash | 进程崩溃 | crashed_at_ms |
| MarketDataDelay | 行情延迟 | venue, delay_ms |
| ArchiveBacklog | 归档积压 | backlog_count |

## 4. 告警状态

```text
Pending -> Acknowledged -> Resolved
                  |
                  v
               Ignored
```

## 5. 告警管理器设计

```text
AlertManager {
    alerts: Vec<AlertEvent>,
}

impl AlertManager {
    pub fn new() -> Self;
    pub fn create_alert(&mut self, level: AlertLevel, alert_type: AlertType, message: String, now_ms: u64) -> AlertEvent;
    pub fn acknowledge_alert(&mut self, alert_id: &str, now_ms: u64) -> Option<&AlertEvent>;
    pub fn resolve_alert(&mut self, alert_id: &str, now_ms: u64) -> Option<&AlertEvent>;
    pub fn ignore_alert(&mut self, alert_id: &str, now_ms: u64) -> Option<&AlertEvent>;
    pub fn get_alerts(&self) -> &[AlertEvent];
    pub fn get_pending_alerts(&self) -> Vec<&AlertEvent>;
    pub fn get_alerts_by_level(&self, level: &AlertLevel) -> Vec<&AlertEvent>;
}
```

pub trait AlertNotifier {

## 7. 失败关闭

- 告警创建必须包含完整的告警信息。
- 告警状态变更必须记录时间戳。
- 告警查询必须支持按级别和状态过滤。
- 告警通知必须支持异步扩展。

## 8. 接入命令

告警管理器可通过以下方式调用：

```text
// 创建告警
let mut manager = AlertManager::new();
let alert = manager.create_alert(
    AlertLevel::Critical,
    AlertType::DatabaseFailure { duration_ms: 5000 },
    "数据库连接失败".to_string(),
    1000,
);

// 确认告警
manager.acknowledge_alert(&alert.alert_id, 2000);

// 解决告警
manager.resolve_alert(&alert.alert_id, 3000);

// 查询待处理告警
let pending = manager.get_pending_alerts();
```

## 9. 发布限制

告警模块只用于系统监控和告警，不影响生产环境配置和运行。真实告警通知需要独立的需求和审批流程。
