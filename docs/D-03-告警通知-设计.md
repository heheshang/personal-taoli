# D-03 告警通知：设计文档

文档状态：`in_progress`。实现告警通知模块。

## 1. 模块边界

- `crates/core/src/notification.rs`：告警通知核心模块，包含通知通道、消息和管理器。

## 2. 通知通道

| 通道 | 描述 | 使用场景 |
|---|---|---|
| Log | 日志 | 调试和审计 |
| Console | 控制台 | 开发和测试 |
| Webhook | Webhook | 集成外部系统 |
| Email | 邮件 | 正式通知 |
| SMS | 短信 | 紧急通知 |

## 3. 通知管理器设计

```text
NotificationManager {
    senders: Vec<Arc<dyn NotificationSender>>,
    results: Arc<RwLock<Vec<NotificationResult>>>,
}

impl NotificationManager {
    pub fn new() -> Self;
    pub fn add_sender(&mut self, sender: Arc<dyn NotificationSender>);
    pub async fn send_notification(&self, message: &NotificationMessage) -> Vec<NotificationResult>;
    pub async fn get_results(&self) -> Vec<NotificationResult>;
    pub async fn clear_results(&self);
}
```

## 7. 失败关闭

- 通知发送必须支持异步操作。
- 通知结果必须记录成功/失败状态。
- 通知历史必须支持查询。
- 所有测试必须在隔离环境运行，不影响生产环境。

## 8. 接入命令

告警通知管理器可通过以下方式使用：

```text
// 创建管理器
let mut manager = NotificationManager::new();
manager.add_sender(Arc::new(LogNotificationSender));

// 创建通知消息
let message = NotificationMessage {
    message_id: "alert-1".to_string(),
    level: "CRITICAL".to_string(),
    title: "Database Failure".to_string(),
    content: "Database connection failed".to_string(),
    timestamp_ms: 1000,
    source: "system".to_string(),
    labels: HashMap::new(),
};

// 发送通知
let results = manager.send_notification(&message).await;
```

## 9. 发布限制

告警通知模块只用于隔离环境验证，不影响生产环境配置和运行。真实告警通知需要独立的需求和审批流程。
